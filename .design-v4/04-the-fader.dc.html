DIRECTION 04 — THE FADER. One page, two lights. Not a theme toggle: a figure/ground inversion under one continuous control.
Mechanism: --x (0…1) drives ground, hairlines, meters, frame aspect & light via color-mix/oklab; text is dual-voice (bench grotesk / stage serif) crossfaded so contrast never dips mid-blend; identity snaps at the cue point like a desk taking a cue.
Structure (new, not the shared wireframe): DECK (fader-first viewport, patch list as nav) → THE PATCH (work as channel strips with inline dossiers, no cards, no page navigation) → THE STAGE (plates widen and take the light as the fader rises) → colophon strip.
Honesty standard: real numbers with provenance only (N=40 EVAL vs 70% baseline; DEVTOOLS-VERIFIABLE); unmeasured = qualitative. All four plates present — full archive, no gaps.
Signature experience: THE FADER itself — native range input (keyboard arrows; touch drag; works on phones, unlike a hover ritual). Canvas ambient: one particle field, two physics — bench grid ticks melting into tungsten bokeh on stage, cursor as probe/key-light by position. Reward: B or BLACKOUT ● kills every light but the cursor's; any key restores.
Type (build): self-hosted grotesk + mono for the bench, self-hosted text serif for the stage (mock uses system stacks; the named faces are chosen at build, not defaulted).
